# Codex for OSS Application Draft

Use this as a starting point for the OpenAI Codex for OSS form.

## Role

Primary maintainer.

## Why this repository qualifies

Fund ETF Dashboard is an early open-source Python/HTML tool for transparent Chinese mutual fund and ETF screening. It integrates TTFund data, multi-period returns, drawdown windows, volatility, Sharpe-like scoring, size filters, and local report generation. The project aims to help developers and retail researchers inspect fund metrics reproducibly instead of relying on opaque screenshots or manual spreadsheet workflows.

## How API credits would be used

API credits would support maintenance work with Codex: reviewing pull requests, triaging issues, improving data-source adapters, adding tests for financial metric calculations, writing documentation, generating release notes, and building safer refresh/cache workflows. Codex would help reduce the maintenance burden as contributors add new data sources and dashboard views.

## Additional notes

The project is early. The next priorities are NAV caching, metric tests, a static demo report, Docker support, and clearer data provenance in the UI.
